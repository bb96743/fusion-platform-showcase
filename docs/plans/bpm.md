## 5. 需要注意

1. **Flowable 会在启动时自动建自己的表**（`act_*` / `flw_*`），所以「库表总数」这类断言必须把它算进去
   （基线 143 表里就包含它们）。若把 `database-schema-update` 关掉，需要自己准备 DDL。
2. **`bpm_*` 表在 `fusion-modules.sql` 里用的是 `IF NOT EXISTS`** —— 重建基线时**不会**清空 bpm 数据；
   但 `system_*` / `infra_*` / QRTZ 是 `DROP + CREATE`，会被清空。
3. **上游的 `oa_leave` 示例**（`PROCESS_KEY = "oa_leave"`）在代码里有常量引用，改造时注意别留下断链。
4. `quartz.sql` 的清理段必须在 `fusion-init.sql` **之后**执行（依赖它清过的 `infra_job`）——见主文档 13.16.7。
